# 10acrefarms.com

Website for 10 Acre Farms — cage-free, free-range chicken and duck eggs, Gwinnett County, GA.

- Plain HTML/CSS, no build step. Hosted on GitHub Pages from `main` (pushing = publishing).
- Read `DECISIONS.md` before changing anything.
- Before every push: `python3 scripts/check.py` (must say PASS).
- Preview locally: `python3 -m http.server -d .` then open http://localhost:8000
